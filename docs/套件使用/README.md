# 套件使用

[English](README.en.md) | 中文

本文档说明 WOL Manager 的日常使用流程。

## 打开应用

安装完成后，在 DSM 主菜单中打开 **WOL Manager**。

如果 DSM 主菜单暂时没有显示入口，可以刷新 DSM 页面或重新登录。仍然看不到时，参考 [故障排查](../故障排查/README.md)。

## 添加设备

1. 点击「添加设备」。
2. 填写设备名称。
3. 填写 MAC 地址，例如 `AA:BB:CC:DD:EE:FF`。
4. 广播地址默认使用 `255.255.255.255`。
5. 端口默认使用 `9`。
6. 点击「保存」。

如果你的网络不允许全局广播，可以把广播地址改成网段广播地址，例如 `192.168.1.255`。

## 唤醒设备

在设备列表中点击对应设备的「唤醒」。应用会发送一个 Wake-on-LAN magic packet。

目标设备需要提前在 BIOS/UEFI、网卡驱动或操作系统里开启 Wake-on-LAN。

## 日常维护

少量设备建议使用界面模式维护。需要批量编辑、备份或迁移设备列表时，使用 [设备管理](../设备管理/README.md) 中的 JSON 模式、导入和导出功能。
