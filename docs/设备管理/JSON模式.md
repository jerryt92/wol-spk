# JSON 模式

[English](JSON-Mode.en.md) | 中文

JSON 模式、导入和导出都使用同一套设备结构。

## 推荐格式

```json
[
  {
    "name": "客厅电脑",
    "mac": "AA:BB:CC:DD:EE:FF",
    "broadcast": "255.255.255.255",
    "port": 9,
    "notes": "可选备注"
  }
]
```

## 兼容格式

导入时也支持外层对象：

```json
{
  "devices": [
    {
      "name": "客厅电脑",
      "mac": "AA:BB:CC:DD:EE:FF",
      "broadcast": "192.168.1.255",
      "port": 9
    }
  ]
}
```

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 否 | 设备 ID。为空时自动生成。 |
| `name` | 是 | 设备名称。 |
| `mac` | 是 | MAC 地址，支持 `AA:BB:CC:DD:EE:FF` 或 `AA-BB-CC-DD-EE-FF`。 |
| `broadcast` | 否 | 广播地址，默认 `255.255.255.255`。 |
| `port` | 否 | UDP 端口，默认 `9`。 |
| `notes` | 否 | 备注。 |
| `updatedAt` | 否 | 更新时间。导入后会由应用重新写入。 |

## 导入行为

- 导入会覆盖当前设备列表。
- 保存前界面会弹出确认提示。
- MAC 地址会自动规范化为大写冒号格式。
- 空 `broadcast` 会自动变成 `255.255.255.255`。
- 空 `port` 会自动变成 `9`。
- 重复 `id` 会自动修正，避免操作冲突。
