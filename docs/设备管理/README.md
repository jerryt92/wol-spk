# 设备管理

[English](README.en.md) | 中文

本文档说明 WOL Manager 的设备列表管理能力。

## 界面模式

界面模式适合日常维护少量设备：

- 添加设备。
- 编辑设备。
- 删除设备。
- 点击唤醒。

保存时会校验必填字段，并自动规范化 MAC 地址。

## JSON 模式

JSON 模式适合批量维护设备列表：

- 点击「JSON 模式」切换到编辑器。
- 点击「格式化」检查 JSON 并自动缩进。
- 点击「保存 JSON」覆盖当前设备列表，保存前会提示确认。
- 点击「重新载入」放弃未保存内容，并恢复当前设备列表。

详细格式见 [JSON 模式](JSON模式.md)。

## 导出 JSON

点击「导出」，浏览器会下载：

```text
wolmanager-devices.json
```

导出内容是设备数组，便于备份和迁移。

卸载套件会删除 NAS 上保存的设备列表。卸载前如果要保留设备，请先导出 JSON。

## 导入 JSON

1. 点击「导入」。
2. 选择 `.json` 文件。
3. 确认覆盖提示。
4. 导入成功后，当前设备列表会被文件内容替换。

导入文件可以是设备数组，也可以是包含 `devices` 数组的对象。
