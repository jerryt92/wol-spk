# Package Center Listing Draft

## Name

WOL Manager

## Category

Utilities

## One-Line Summary

Manage Wake-on-LAN devices and wake local network machines from Synology DSM.

## Description

WOL Manager is a native DSM utility for Wake-on-LAN device management. It helps Synology users add local network devices, store MAC address and network information, and send Wake-on-LAN magic packets from the NAS.

The package provides a DSM-friendly interface for daily use, including add, edit, delete, and wake actions. It also includes JSON mode for bulk editing, backup, import, export, and migration.

WOL Manager does not require Docker or an additional runtime on the NAS.

## Highlights

- Native DSM 7 package.
- Manage Wake-on-LAN device profiles.
- Send Wake-on-LAN magic packets from the NAS.
- Configurable broadcast address and UDP port.
- JSON import/export for backup and migration.
- No Docker or extra runtime dependency.

## Requirements

- DSM 7.0 or later.
- x86_64 Synology NAS.
- Target devices must support and enable Wake-on-LAN.
- Wake-on-LAN traffic must be allowed by the local network.
